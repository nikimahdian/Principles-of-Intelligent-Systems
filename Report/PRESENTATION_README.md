# راهنمای استفاده از ارائه‌ها

## فایل‌های ارائه

دو فایل ارائه ایجاد شده است:

1. **presentation.tex** - ارائه کامل با جزئیات بیشتر (مناسب برای ارائه‌های طولانی‌تر)
2. **presentation_7min.tex** - ارائه فشرده برای ۷ دقیقه (مناسب برای ارائه‌های کوتاه)

## نحوه کامپایل

### روش ۱: استفاده از اسکریپت (ساده‌تر)

فایل `compile_presentation.bat` را اجرا کنید:
```bash
compile_presentation.bat
```

### روش ۲: کامپایل دستی

برای کامپایل ارائه کامل:
```bash
xelatex presentation.tex
xelatex presentation.tex
```

برای کامپایل ارائه ۷ دقیقه‌ای:
```bash
xelatex presentation_7min.tex
xelatex presentation_7min.tex
```

## نکات مهم

1. **فونت‌ها**: مطمئن شوید فونت‌های فارسی در پوشه `font/` موجود هستند
2. **مسیر فونت**: اگر فونت‌ها در مسیر دیگری هستند، مسیر را در خط `\settextfont` تغییر دهید
3. **کامپایل**: همیشه دو بار کامپایل کنید تا فهرست مطالب و ارجاعات درست شوند

## سفارشی‌سازی

### تغییر تم

در خطوط زیر می‌توانید تم را تغییر دهید:
```latex
\usetheme{Berlin}  % یا Madrid, Warsaw, و غیره
\usecolortheme{seahorse}  % یا default, dolphin, و غیره
```

### تغییر رنگ‌ها

رنگ‌های مهم در ارائه ۷ دقیقه‌ای:
```latex
\definecolor{important}{RGB}{200,0,0}  % قرمز برای تاکید
\definecolor{highlight}{RGB}{0,100,200}  % آبی برای برجسته کردن
```

### اضافه کردن اسلاید

می‌توانید اسلایدهای جدید اضافه کنید:
```latex
\begin{frame}{عنوان اسلاید}
محتوای اسلاید
\end{frame}
```

## عکس‌ها و نمودارها

برای اضافه کردن عکس‌ها:
```latex

\includegraphics[width=0.8\textwidth]{img/filename.png}
\caption{توضیحات}
\end{figure}
```
